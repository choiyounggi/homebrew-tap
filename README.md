# homebrew-tap

**English** | [한국어](README.ko.md)

Homebrew tap for [mac-inputlock](https://github.com/choiyounggi/mac-inputlock) and
[claude-proxy-router](https://github.com/choiyounggi/claude-proxy-router).

```bash
brew install --cask choiyounggi/tap/inputlock
brew install choiyounggi/tap/claude-proxy-router
```
